| 位置 | 用途 |

## 常用布局

- `SiteShell`：导航、正文、页脚和滚动区域。
- `PageTemplate`：页面标题和内容容器。
- `PageSection`：带标题的内容分区。
- `PageScreen`：一屏高度的内容区。
- `PageBackground`：固定页面背景。
- `CardRevealGroup` / `CardReveal`：卡片顺序入场。

布局组件见 [src/components/layout](../src/components/layout)，卡片功能见 [src/features/cards](../src/features/cards)。
